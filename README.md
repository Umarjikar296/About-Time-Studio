# ABOUT TIME STUDIOS — website starter

A bilingual (English/German) Next.js App Router starter for ABOUT TIME STUDIOS, styled with Tailwind CSS and custom CSS. Uses JavaScript, Space Grotesk and Inter.

## Run locally

1. Install Node.js 18.17+ (Node 20 LTS recommended).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Before publishing

- Replace the illustrative concept projects with your own original work or keep them clearly labelled as concepts.
- Confirm package scope and pricing before advertising it.
- Update the contact email if needed. The form currently opens a pre-filled email through `mailto:`; it does not store or send submissions automatically. For production, connect a form provider or server-side endpoint and test delivery.
- Add a proper Impressum and Datenschutzerklärung and check the requirements that apply to your business and website. Current footer links are placeholders, not legal pages.
- Consider adding consent management if you later add analytics, marketing pixels, or non-essential cookies.
- Test keyboard navigation, mobile layouts, form flow, and the production build.
